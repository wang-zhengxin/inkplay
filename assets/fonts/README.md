# 游戏字体

Ma Shan Zheng Regular，来源：[Google Fonts 官方字体库](https://github.com/google/fonts/tree/main/ofl/mashanzheng)。

字体原文件随项目保存，页面只从本机加载，游玩时无需访问字体服务。使用 SIL Open Font License 1.1，完整许可见同目录 OFL.txt；保留字体中的版权信息和许可文件。

英文使用 Lora 正体，来源：[Google Fonts 官方字体库](https://github.com/google/fonts/tree/main/ofl/lora)。原始可变字体保存为 Lora-Variable.ttf，使用 400 字重，标题可使用 500；完整 SIL Open Font License 1.1 许可见 Lora-OFL.txt。关卡文字使用固定字号，长短片段不自动缩小或横向压缩，允许自然延伸并交叠；英文单词边界依据真实字宽计算。
