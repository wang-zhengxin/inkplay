# 字间漫游 · INKPLAY

参考 Casus Liber 的「文字平台 + 墨点」玩法，重新实现的中文版小游戏与关卡工坊。本项目独立实现玩法与编辑器。默认包含 100 个随机生成的双语关卡。无第三方依赖，不需要联网加载字体、图片或音效。

## 启动

需要 Node.js 22 或更高版本。在此目录运行：

```sh
npm start
```

浏览器访问 http://127.0.0.1:4173，首页铺满浏览器视口并自动进入游戏，无需点击开始。右下角操作规则淡显后在 9 秒内自动淡出，右上角齿轮图标进入独立的创作页面 http://127.0.0.1:4173/editor.html。macOS 也可以双击 `启动游戏.command`。如果端口已被使用，可运行 `PORT=4174 npm start`。ES modules 需要通过 HTTP 打开，请不要直接双击 `index.html`。

## 玩法

- A / D 或 ← / → 移动，按住 W / ↑，每次落到文字上都会继续跳跃；松开停止连跳。下落时松开并再次按住跳跃可以滑翔。
- 空格消耗墨水变大，并提升跳跃力度。拾取墨水恢复 45%。
- 从屏幕左侧中部出发，文字路线在上下错落中向右下延伸；接触最后一组文字后的箭头即可翻关，星光可选收集。
- 掉出画布或碰到障碍会重生，本章的收集物重置。R 重来，Esc 进入创作页面。
- 触碰起点文字旁的左箭头可以返回上一关，落在上一关末尾；上下关箭头为没有圆圈的手绘线条。首尾循环，翻页时保留本次游玩的收集物与墨水；R 重来会清除当前章进度。接触右箭头时整页向右滑动，接触左箭头时整页向左滑动，约 0.62 秒完成；转场期间暂停物理运动，完成后继续操作。翻页自动完成，无通关按钮。
- 触屏设备显示淡色的移动、跳跃、变大按钮。

## 100 关与英文版

游戏主页面右上角的「中 / EN」按钮可即时切换语言，保留当前章节、已收集星光、墨水和游玩统计，偏好保存在本机；站在文字上时落点随新语言字形调整，空中切换延续原运动。设置图标仍进入创作页。

默认关卡由固定随机种子生成：100 个不同的内容组合和布局，每关都有中文与英文。保持左侧中部出发、右下结束的路线，平台之间保留跳跃间隙。出生点、星光、墨水及出口会跟随当前语言的文字落点。已有未经修改的默认五关会升级为 100 关；自定义关卡保留，并追加 100 个随机关卡。

齿轮 → 内容 →「游戏语言」可切换中文 / English，返回游戏后生效并自动保存。英文按完整单词绘制与碰撞，词内连续，词间留空；连字符、撇号与长单词不会拆开。每个平台的中文和 English 可分别编辑，未填写英文时保留原文字。

内容页的「随机世界 · 100 关」可以输入随机种子，再点击「重新生成 100 关」。同一种子复现相同关卡，更换种子会得到新内容与布局；重新生成会替换整套章节，支持撤销，保留主题、皮肤、声音和规则。默认种子为 20260930。中英文示例作品分别为 `examples/paper.inkplay.json` 和 `examples/english.inkplay.json`。

## 自定义

点击游戏页右上角的齿轮进入 `editor.html`。工坊包含章节、内容、外观、声音、规则、素材上传与作品导入导出；「返回游戏」会先保存最新修改，再直接运行当前章节。创作模式中点击或拖动对象，在「内容」页修改坐标、文字、宽度、字号和字间空隙。每个非空白字符独立参与碰撞，字与字之间没有隐形地板，间隙足够大时墨点会掉下；装饰文字不参与碰撞。默认墨点半径 4.5 px。随机排列将文字按 1–10 字分组，组内字距围绕 2 px 小幅变化，组间距在 18–40 px 内随机；随机种子固定排布，绘制和碰撞使用同一结果。宽度不足时会缩小字距以容纳文字。出生点可移动，每章各一个。出口自动紧跟最右侧的实际文字末端，编辑文字、位置、宽度、字号或字距时同步更新，出口坐标无需手工调整。

游戏页以关卡整体内容的中心垂直居中，文字、小球与箭头一同上移，四周留白，等比缩放且限制最大字号；纸张背景仍铺满视口。默认 100 关从左侧中部出发、在右下结束，文字、位置、宽度、字距均随机变化，排布算法先测量中英文的实际文字边界，再随机分配横向留白和纵向步幅，避免长片段把下一段挤在一起。回折位置随机选择，也有一路向下的关卡；约四成关卡在随机一个接缝出现少量边缘交叠（横向重叠 12–34），相邻段落纵向距离至少 28，不再固定挤在第二、第三段。同一种子可复现；另外保留五种斜向下布局模板。窄屏采用横向跟随，文字只显示在中央留白区域，末尾箭头随最后一组字进入画面。内容页可应用布局模板，再自由拖动；选中文字后可调整分组字数（1–10）、组内字距、组间距范围、随机种子或重新随机生成。旧版未经改动的默认关卡会更新布局，自定义文字和平台坐标保持原样，出口统一跟随末尾文字。墨点起跳时拉伸、落地时压扁并弹性回弹；形变保持脚底位置与碰撞尺寸，减少动态效果模式下保留圆形。默认中文使用本地毛笔字体 Ma Shan Zheng，默认英文使用本地 Lora 正体，并按真实字宽分配单词边界。关卡文字统一使用原始字号，不按片段长度缩小或横向压缩；较长片段可自然延伸、交叠，碰撞范围和出口跟随实际文字长度。许可与来源见 `assets/fonts/README.md`；也可在工坊切换宋体、等宽字体或无衬线字体。

游戏页隐藏编辑器 HUD、章节文字、系统标题与英文标语，仅显示游戏内容、入口图标和短暂的操作提示。自定义装饰文字仍在游戏中显示。声音由首次按键或触摸启用，以符合浏览器的音频播放要求；角色和物理逻辑从页面加载后即运行。

- **章节**：新建、复制、删除，最多 200 章，每章最多 250 个对象。
- **外观**：默认黑白水墨主题，另有苔绿纸页、午夜书房、潮汐来信、落日手稿；自定义配色、字体、背景图片；墨点/星星/叶子皮肤或上传图片；墨水状态栏位置和可见性。
- **声音**：3 个合成音色、主音量、跳跃/落地/收集/重生/通关的独立音频，以及循环背景音乐。
- **规则**：移动速度、跳跃、重力、墨点半径、变大倍率、墨水消耗、作品名。镜头默认随墨点上下移动，整页文字在跳跃和落地时跟着起落，沿斜坡落地后回到构图基准，并将跟随范围限制在页面留白内；跟随强度与速度可调，强度设为 0 可固定画面。创作时镜头固定以方便拖拽。
- **编辑**：网格吸附、图层选择、复制对象、删除、30 步撤销/重做。Ctrl / ⌘ Z 撤销，Ctrl / ⌘ Shift Z 重做。
- **导入导出**：JSON 包含完整章节、主题、皮肤、音频与背景。图片限制 1 MB，音频限制 2 MB，作品素材总量 18 MB。支持当前浏览器可解码的音频；图片支持 PNG / JPEG / WebP / GIF。

作品自动保存在当前浏览器的 IndexedDB 中，游戏与工坊共享存档，包括上传素材。清理浏览器数据、更换浏览器或更换端口后不共享存档，请使用「导出作品」备份。当前游戏章节保存在当前标签页会话中；工坊里的试玩通关标记仅存在于当前会话，不包含在作品文件中。示例作品见 `examples/paper.inkplay.json`。

## 扩展代码

| 文件 | 职责 |
| --- | --- |
| `src/model.js` | 版本化 JSON 配置、默认关卡、主题注册表 `THEMES`、对象类型 `TYPES`、配置校验与碰撞生成 |
| `src/engine.js` | 独立物理引擎，固定步长更新；`onEvent(event)` 提供 jump / land / collect / death / win / previous 事件 |
| `src/render.js` | Canvas 绘制、对象外观、角色皮肤绘制 |
| `src/bounce.js` | 小球起跳、落地形变与弹性回弹 |
| `src/camera.js` | 平滑跟随墨点的纵向镜头，独立于世界碰撞坐标 |
| `src/viewport.js` | 左中起点与右下终点的留白构图、窄屏横向跟随 |
| `src/navigation.js` | 双向翻关、文字末端箭头、上一关落点及游玩期间的章节进度 |
| `src/transition.js` | 左右滑动转场的时间、缓动和百分比位移 |
| `src/layout.js` | 随机种子、中文 1–10 字分组、英文整词分组与可变字距，共用于绘制和碰撞 |
| `src/route-layout.js` | 按双语实际字宽排布，随机分配上下步幅、回折位置、留白与少量交叠 |
| `src/campaign.js` | 100 关的可复现随机生成、双语文本与文字落点锚定 |
| `src/audio.js` | Web Audio 默认音效、独立事件音频、背景音乐 |
| `src/storage.js` | IndexedDB 作品读写 |
| `src/game.js` | 首页自动运行、操作提示、触屏输入、音频唤醒与自动翻章 |
| `src/app.js` | 独立工坊界面、编辑历史、拖拽、输入与素材导入导出 |
| `index.html` / `game.css` | 全屏游戏页面，只保留创作入口图标 |
| `editor.html` / `styles.css` | 独立的响应式工坊界面 |

增加主题：在 `THEMES` 增加一个颜色配置，主题选择器会自动生成。增加皮肤：扩展配置校验、外观选择器与 `Renderer.player()`。增加对象：注册 `TYPES`，实现边界、绘制、编辑表单与碰撞/触发逻辑。所有导入内容经过校验，不执行导入的代码，不加载远程素材 URL。

创作世界尺寸为 1000 × 620，行进边界会按末尾文字与箭头位置延伸。全屏游戏按文字区域等比缩放并整体垂直居中，起点在左侧、终点位于内容区域右下，窄屏横向跟随，跳跃时纵向跟随；创作工坊显示整张关卡便于编辑。暂不包含无限滚动关卡、在线分享服务或多人游戏。

新增检查覆盖 100 关内容与布局唯一性、种子复现、中英文导出往返、旧存档升级保护、完整单词碰撞、词间掉落，并通过实际输入模拟验证默认种子及 0、42、4294967295 共四组种子的 800 条中英文路线可集齐星光并通关；检查回折和交叠在不同接缝的分布、双语实际文字边界、旧版随机存档的安全升级。
